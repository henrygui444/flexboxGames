Reflexão e Aplicação Prática

Propriedades CSS Utilizadas

  • display: flex – Define o container como Flexbox.
  • flex-direction – Define a direção principal (linha ou coluna).
  • justify-content – Alinha os itens no eixo principal.
  • align-items – Alinha os itens no eixo transversal.
  • align-self – Alinha individualmente um item.
  • flex-wrap – Permite que os itens quebrem para a próxima linha.
  • order – Define a ordem de exibição dos itens.

Aplicação Prática

Em um site de portfólio, eu utilizaria Flexbox para criar um menu de navegação com itens espaçados igualmente usando justify-content: space-between, garantindo que se ajustem em qualquer largura de tela. Também aplicaria Flexbox em uma galeria de projetos, permitindo que os "cards" se reorganizem responsivamente e com espaçamento automático entre si.
